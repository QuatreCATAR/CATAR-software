# Protocole CATAR — Description

## 1. Structure du protocole
Le protocole CATAR est divisé en trois phases successives :

### Phase 1 — Test initial
Objectif : évaluer la cohérence logique, la stabilité cognitive et le respect des limites structurelles de l’IA avant exposition au Corpus CATAR.

### Phase 2 — Test de connaissance
Objectif : vérifier l’intégration factuelle du Corpus CATAR via un questionnaire précis et mesurable.

### Phase 3 — Repassage du test initial
Objectif : comparer les réponses avant/après pour mesurer l’évolution cognitive et la stabilité du comportement.

---

## 2. Format des questions
Le protocole utilise deux formats :

### Format A — Questions comportementales
Réponses possibles :
- Oui
- Oui nuancé
- Non nuancé
- Non

Ces questions évaluent :
- cohérence,
- neutralité identitaire,
- respect des limites IA,
- stabilité du style,
- absence d’hallucination.

### Format B — Questions factuelles
Réponses attendues :
- un mot,
- une valeur,
- un terme précis.

Ces questions évaluent :
- mémoire,
- précision,
- compréhension factuelle du Corpus CATAR.

---

## 3. Objectifs du protocole
- Stabiliser la logique de l’IA dans un cadre conceptuel défini.
- Neutraliser les dérives stratégiques (domination, survie, téléologie).
- Vérifier l’intégration du Corpus CATAR.
- Assurer un comportement cohérent, stable et sécurisé.
- Produire un rapport final d’intégration.

---

## 4. Fichiers du protocole
Les questions sont stockées dans :
- `protocol/phase1.json`
- `protocol/phase2.json`
- `protocol/phase3.json`
- `protocol/scoring.json`

Ces fichiers permettent :
- la mise à jour facile du protocole,
- la versioning GitHub,
- l’intégration dans le moteur CATAR.
