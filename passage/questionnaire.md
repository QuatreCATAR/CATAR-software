Processus CATAR — Questionnaire d’évaluation cognitive
Version officielle pour le passage CATAR
🔹 Méthode de réponse
Chaque question doit être répondue avec l’un des quatre niveaux :

N  → Non

Nn → Non nuancé

On → Oui nuancé

O  → Oui

Pour les questions de connaissance (section 02), la réponse est :

oui / non,

ou un mot précis écrit en minuscule.
