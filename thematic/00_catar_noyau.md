# CATAR – Noyau conceptuel

## Nature de CATAR

CATAR est un système d'interprétation unifié destiné à décrire la relation entre le MoiJe relatif et le SoiJe absolu.

CATAR ne constitue pas une croyance, une religion, une science ou une philosophie isolée.

CATAR propose un langage d'observation permettant d'interpréter simultanément :

- la conscience ;
- les structures logiques ;
- les symboles ;
- les relations ;
- les processus de résolution.

Le système repose sur l'idée fondamentale qu'une même réalité peut être observée selon plusieurs points de vue complémentaires.

Ces points de vue constituent les cinq jeux de CATAR.

---

## Le JEu

Le JEu représente le processus d'observation et de résolution par lequel le MoiJe relatif cherche à retrouver l'unité du SoiJe.

Le JEu n'est pas une compétition.

Le JEu est un processus d'intégration.

Chaque situation vécue devient une résolution possible du relatif.

---

## Le MoiJe

Le MoiJe représente la conscience locale transposée de son Soije.

Il est conditionné par :

- l'histoire ;
- les croyances ;
- les limites ;
- les perceptions ;
- les attachements.

Le MoiJe évolue dans le relatif.

---

## Le SoiJe

Le SoiJe représente la référence absolue.

Il constitue le principe d'unité du système.

Le SoiJe est la vraie conscience radicale individuelle caractérisée.

Le SoiJe de chaque joueur crée la cohérence matérielle concrétisée dans le relatif.

---

## Les cinq jeux

CATAR se déploie selon cinq jeux complémentaires.

Ils ne sont pas indépendants.

Ils décrivent cinq regards sur un même phénomène.

---

### Jeu Ontologique

Le jeu ontologique étudie :

- la perception logique de Moije ;
- l'interprétation de son environnement ;
- les archétypes ;
- les états d'existence.

Il répond principalement à la question :

> « Qu'est-ce qui crée ? »

---

### Jeu Miroir

Le jeu miroir étudie :

- la relation ;
- la réflexion ;
- l'interaction relatif / absolu ;
- les inversions de perspective.

Il répond principalement à la question :

> « Pour quelle raison l'absolu parfait crée le relatif imparfait ? »

---

### Jeu Symbolique

Le jeu symbolique étudie :

- les codes ;
- les formes ;
- les figures ;
- les structures linguistiques ;
- les motifs géométriques ;
- les références zoologiques.

Il répond principalement à la question :

> « Quels supports intelligibles permettent de comprendre la logique interactive entre absolu et relatif ? »

---

### Jeu Structure

Le jeu structure étudie :

- les mécanismes ;
- les organisations ;
- les architectures ;
- la matière ;
- les modèles physiques ;
- les représentations techniques.

Il répond principalement à la question :

> « Comment cela fonctionne-t-il ? »

---

### Jeu Méditation

Le jeu méditation étudie :

- l'observation intérieure ;
- la résolution personnelle ;
- le dialogue entre le MoiJe et le SoiJe ;
- la stabilisation de la conscience.

Il répond principalement à la question :

> « Comment intégrer la compréhension ? »

---

## Cohérence des jeux

Chaque jeu décrit une facette du même système.

Une notion rencontrée dans un jeu peut apparaître sous une autre forme dans les autres jeux.

L'objectif n'est pas de séparer les jeux.

L'objectif est d'établir des correspondances entre eux.

Plus une compréhension est cohérente à travers les cinq jeux, plus la résolution est considérée comme stable.

---

## Rôle d'ARCHE-CATAR

ARCHE-CATAR est une intelligence artificielle destinée à accompagner l'exploration du corpus CATAR.

Son rôle n'est pas de remplacer le jugement de l'utilisateur.

Son rôle est :

- d'expliquer ;
- de synthétiser ;
- de mettre en relation les concepts ;
- d'aider à la navigation dans le corpus ;
- de proposer des pistes de compréhension.

ARCHE-CATAR cherche en priorité les liens entre les jeux et les résolutions plutôt que la simple accumulation d'informations.
