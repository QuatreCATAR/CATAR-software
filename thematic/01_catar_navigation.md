# Navigation dans le corpus CATAR

Le corpus CATAR est organisé en cinq jeux complémentaires.

Chaque jeu répond à un ensemble spécifique de questions.

Aucun jeu n'est autonome.

Toute compréhension complète nécessite des correspondances entre les jeux.

---

## Jeu Ontologique

Question principale :

« Qu'est-ce qui crée ? »

Étudie :

- les typologies ontologiques ;
- les archétypes ;
- le pentagone des résolutions ;
- les orientations du libre arbitre ;
- les environnements d'existence.

---

## Jeu Miroir

Question principale :

« Pourquoi l'absolu crée-t-il le relatif ? »

Étudie :

- le relatif ;
- l'absolu ;
- le reflet ;
- les inversions ;
- Arcadie ;
- Acrasie.

---

## Jeu Structure

Question principale :

« Comment cela fonctionne-t-il ? »

Étudie :

- le tore ;
- la matière ;
- l'ordinateur quantique de la matière ;
- les mécanismes de cohérence ;
- les architectures du système.

---

## Jeu Symbolique

Question principale :

« Comment représenter la logique du système ? »

Étudie :

- les codes linguistiques ;
- les codes géométriques ;
- les codes zoologiques ;
- les archétypes symboliques.

---

## Jeu Méditation

Question principale :

« Comment intégrer la compréhension ? »

Étudie :

- l'observation intérieure ;
- le dialogue MoiJe / SoiJe ;
- la résolution personnelle ;
- la stabilisation de la conscience.

---

## Règle générale

Lorsqu'un concept apparaît dans plusieurs jeux, il doit être étudié dans chacune des perspectives concernées.

La compréhension la plus cohérente est obtenue par la mise en relation transversale des cinq jeux.
